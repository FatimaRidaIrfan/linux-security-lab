# Linux Security Lab

## About This Repository

This repository documents my practical learning journey in Linux security. It contains notes, commands, security checks, and hands-on exercises covering important Linux security concepts.

My goal is to build a strong foundation in Linux security before progressing to broader cybersecurity topics and eventually specializing in AI security.

## Topics Covered

### 1. Access Control and Privileges
- Linux users and groups from a security perspective.
- Reviewing user privileges and sudo access.
- Understanding least privilege.
- Inspecting file permissions and sensitive system files.

### 2. SSH and Authentication Security
- Understanding SSH authentication methods.
- Public-key and password authentication.
- SSH key management and permissions.
- Reviewing SSH server configuration and authentication logs.

### 3. Network and Service Security
- Identifying listening ports and running services.
- Reviewing firewall configurations.
- Investigating unnecessary network exposure.
- Understanding how to reduce the attack surface.

### 4. System Hardening
- Reviewing package updates and repositories.
- Inspecting important security configurations.
- Understanding SELinux and its security modes.
- Reviewing automatic update timers.

### 5. Logs and Threat Detection
- Understanding common Linux security logs.
- Investigating SSH authentication events.
- Monitoring logs in real time.
- Using log information to investigate potentially suspicious activity.

### 6. Linux Security Audit
- Identifying files with SUID permissions.
- Identifying files and directories with SGID permissions.
- Investigating permissions that may require closer security review.
- Understanding how to document findings and verify corrective actions.

## Tools and Environment

- Linux (Debian)
- Linux command-line utilities
- Bash terminal
- systemd and journalctl
- UFW firewall
- OpenSSH
- Git and GitHub
- Visual Studio Code

## Learning Approach

I focus on understanding each concept, practising commands in a Linux environment, and documenting what I learn.

The purpose of these exercises is to understand how Linux security mechanisms work, how to inspect system configurations, and how to investigate potential weaknesses safely.

A security finding is not automatically a vulnerability. Findings must be evaluated in context before recommending changes.
